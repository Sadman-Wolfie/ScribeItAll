# 🩸 ScribeItAll

A Manifest V3 Chrome Extension that uses dark arts (and local JavaScript) to siphon the essence of any webpage and transmute it into clean, readable Markdown. 

## Features
* **Sinister UI:** A massive, overlapping pentacle core with coagulated scarlet rings and breathing status text.
* **Pure Extraction:** Bypasses visual clutter and ads using Mozilla's Readability.
* **Offline Transmutation:** Uses a localized `turndown.js` script to convert HTML to Markdown without relying on external API calls or sending your data to a server.
* **Instant Archive:** Automatically seals the pact and downloads the `grimoire_[title].md` file directly to your local machine.

## Installation
1. Clone this repository to your local machine.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the `ScribeItAll` folder.
5. Pin the extension to your toolbar, navigate to an article, and click the icon to begin the ritual.
